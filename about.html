How this was built

This project was built with AI coding assistance throughout: Claude Code (Anthropic) wrote and iterated on the exact dynamic-programming solver, the Monte Carlo verification code, the practice game, the pixel art generation scripts, and this website. A second, independent AI model was used separately for adversarial review of the math and the simulation code, specifically to catch mistakes the first model might not catch in its own work. None of this replaces responsibility for the result. Every numerical claim in the strategy report is checked against independent simulation, and the full source is public on GitHub for anyone to read or challenge.

Commitments

Privacy and no tracking

This site collects nothing about you. No analytics, no tracking pixels, no third-party scripts, no cookies. See the audit below for exactly how that was checked, not just asserted.

Security

There is no backend, no account system, no form that sends data anywhere, and no database. There is nothing to collect because nothing is stored in the first place, which also means there is nothing here to breach. The site is served over HTTPS with a certificate issued for this domain specifically. All source code is public and auditable.

No monetization, except a voluntary tip jar

No ads, no paywalls, no affiliate links, no selling of data (there is no data to sell). The only monetization-adjacent thing on this site is a voluntary Ko-fi link in the footer: entirely optional, never required for any feature, and not tied to anything this site knows about you, because it does not know anything about you. Following that link takes you to Ko-fi's own site, governed by Ko-fi's own practices, not this one.

History: what changed and why

Earlier versions of this site included Google Analytics (GA4). On review, that GA4 property had collected zero events in its entire lifetime, so removing it lost no data. Rather than fix or replace it, the decision was to remove analytics entirely and commit to none, rather than hedge with a cookieless or non-identifying alternative.

Two privacy-respecting, cookieless analytics tools (Cloudflare Web Analytics and GoatCounter) were considered and deliberately not added, even though neither sets a persistent identifier or stores an IP address. The Privacy First Pledge (an independent, self-certified pledge for sites like this one) states the principle plainly: do not collect data just because you can, and default to discarding it, not collecting it. That is the standard this site chose to hold itself to, rather than the lower bar of "non-identifying is good enough."

The 512KB Club (a web performance pledge, often tracker-free as a side effect of its size limit) was also checked for honesty's sake. This site does not qualify: its pages are over 1.1MB each, mostly embedded pixel art, photography, and a custom font, well over twice even that club's loosest threshold. No claim is made to that badge.

Method

Checked by reading every line of the page source for script tags, external resource references, cookie or storage API usage, iframes, and network-call code, then separately verified by loading each page in a real browser and recording every network request made, including after starting a match and rolling dice, to catch anything a source read-through alone might miss.
